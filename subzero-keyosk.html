Sovereign Airgapped Bitcoin Entropy Appliance (Amnesic Guest Mode Kiosk)

SubZero-HTML is a zero-dependency, single-file HTML/WASM application designed strictly for execution on volatile, amnesic boot environments. It contains zero external network calls, zero tracking, and strictly limits execution via standard W3C Content-Security-Policy (CSP).

Approved Amnesic Deployment Targets

  • ChromeOS Guest Mode (Chromebooks): Verified deployment model. Utilizes ChromeOS's cryptographically bound ephemeral ext4 user partitions, which are aggressively destroyed upon Guest Mode exit. Highly resistant to malware persistence.
  • macOS Guest User (MacBooks): Verified deployment model. Apple macOS mounts a temporary, isolated APFS volume for Guest Users, strictly enforced by FileVault. The entire volume is securely destroyed immediately upon logout.
  • Tails OS / ShredOS (Live USB): Verified but requires x86 ISO flashing capabilities. ChromeOS/macOS Guest modes are structurally preferred for extreme non-technical operational simplicity.
